Як експортувати звіт і передати його підряднику

JSON і CSV у Complete: що передати, як пояснити область і перевірити файл.

Опубліковано й перевірено: 20 жовтня 2026

Експорт корисний, коли результати потрібно перенести в таблицю чи систему задач. Передавайте разом із файлом короткий опис області та обмежень. Сам перелік знахідок не пояснює, які сторінки залишилися поза обходом і чому частину перевірок не виконано.

У цьому матеріалі

  • Перевірте доступність експорту
  • Виберіть формат за задачею
  • Підготуйте супровідний опис
  • Перевірте безпечне використання таблиці
  • Якщо файл не завантажується

Перевірте доступність експорту

Потрібен завершений звіт пакета Complete. Basic не включає експорт та історію проблем. Відкрийте перевірку у «Звіти» й переконайтеся, що це потрібний домен, дата та пакет. Не замінюйте відсутню функцію копіюванням конфіденційних даних акаунта зі сторінки браузера.

Врахуйте строк зберігання результатів: для Complete він становить 365 днів. Якщо ваш процес вимагає архіву довше, збережіть дозволений експорт у власному робочому сховищі й визначте доступ до нього.

Виберіть формат за задачею

CSV зручний для таблиці, групування URL і розподілу задач. JSON зберігає структуровані дані для власних інструментів. Експорт JSON/CSV не означає наявність PDF-звіту чи автоматичного створення задач у сторонній системі.

  1. Відкрийте доступні дії експорту в готовому звіті.
  2. Виберіть формат і дочекайтеся завантаження.
  3. Збережіть файл під назвою з доменом та датою, щоб не змішати різні запуски.
  4. Відкрийте файл і перевірте український текст, адреси та наявність очікуваних даних.

Підготуйте супровідний опис

Напишіть: «Аудит example.com від 14.10.2026; Complete; український розділ /uk/; параметри URL ігнорувалися; ліміт сторінок досягнуто; у продуктивності немає польових даних для частини URL». Це навчальний приклад опису, а не результат реальної перевірки.

Додайте три першочергові групи робіт і критерії приймання. Наприклад: виправити canonical у шаблоні послуги; перевірити HTTP-відповідь, вихідний HTML і всі мовні представники після публікації. Підряднику потрібне пояснення рішення, а не тільки колонка з рівнем серйозності.

Перевірте безпечне використання таблиці

Імпортуйте CSV штатним імпортом таблиці з правильною кодувальною схемою. Дані сторінки можуть містити незвичайні символи; не виконуйте вміст клітинок як команди чи формули. Перегляньте дані перед пересиланням: публічні URL іноді містять параметри, які не варто поширювати ширше робочої команди.

Збережіть початковий експорт окремо від відредагованого плану. Так можна повернутися до первісного доказу та відрізнити висновок сканера від рішення людини.

Якщо файл не завантажується

Перевірте, чи завершилася перевірка, чи пакет включає експорт і чи браузер не заблокував завантаження. Не запускайте новий оплачуваний аудит тільки заради повторної спроби скачати існуючий файл. Запишіть ідентифікатор звіту, формат і повідомлення про помилку для підтримки; не додавайте токени доступу.
