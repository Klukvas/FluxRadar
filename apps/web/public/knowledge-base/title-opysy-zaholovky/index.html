Як перевірити title, опис і структуру заголовків

Перевірка метаданих на різних шаблонах: дублікати, зміст сторінки та читабельна ієрархія.

Опубліковано й перевірено: 20 жовтня 2026

Title, meta description і заголовки мають описувати реальну сторінку. Мета перевірки — допомогти людині й пошуковику розрізняти матеріали. Підганяти всі тексти під однакову кількість символів без аналізу змісту не потрібно.

У цьому матеріалі

  • Виберіть представників шаблонів
  • Зіставте title зі змістом
  • Перевірте description
  • Перевірте заголовки як план матеріалу
  • Контроль після публікації

Виберіть представників шаблонів

Візьміть головну, сторінку послуги, категорію, товар і статтю, які є на вашому сайті. Запустіть SEO-модуль Basic або Complete та відкрийте відповідні знахідки. Якщо однакові метадані повторюються на багатьох адресах, перевірте джерело в шаблоні CMS.

Для багатомовного сайту перегляньте кожну мову. Український заголовок сторінки поруч з англійським title може бути помилкою перекладу шаблону, а не проблемою однієї статті.

Зіставте title зі змістом

  1. Перегляньте title у вихідному HTML та вкладці браузера.
  2. Перевірте, чи він називає основний предмет сторінки й розрізняє її серед інших.
  3. Приберіть застарілі ціни, непідтверджені суперлативи та повторення ключових слів.
  4. Відкрийте схожі сторінки й порівняйте назви.

«Послуги | Компанія» на всіх сторінках гірше пояснює різницю, ніж «Ремонт кавомашин у Львові | Компанія». Це приклад формулювання, а не гарантія певного вигляду результату пошуку.

Перевірте description

Опис повинен стисло пояснювати пропозицію чи користь конкретного матеріалу. Не вставляйте однакове рекламне речення на всі URL. Для сторінки доставки доречні зона, умови й спосіб замовлення, якщо ці відомості справді є на сторінці.

Google може сформувати фрагмент із видимого тексту замість description. Орієнтири довжини корисні для редагування, але відображення залежить від запиту й пристрою. Проблема не вирішується обрізанням опису на довільному символі.

Перевірте заголовки як план матеріалу

Прочитайте тільки H1–H3. Чи зрозумілий предмет і порядок розділів? Основний заголовок має відповідати сторінці, H2 — називати її великі частини, H3 — пояснювати підрозділи. Не використовуйте рівень заголовка лише заради розміру шрифту.

Кілька H1 у валідній структурі не є самостійним доказом SEO-катастрофи. Оцініть ясність семантики. Для послуги план «Що ремонтуємо → Як працюємо → Умови → Контакти» корисніший за повторення одного ключового словосполучення в кожному заголовку.

Контроль після публікації

Збережіть зміни в CMS і перевірте живий HTML, а не тільки редактор. Очистіть або дочекайтеся оновлення кешу за вашим процесом. Повторіть цільову перевірку на кількох URL шаблону. Очікуваний результат — точні унікальні метадані та зрозумілий план; швидка зміна фрагмента Google після цього не гарантована.
