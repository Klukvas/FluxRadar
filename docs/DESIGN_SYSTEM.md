# DESIGN_SYSTEM — FluxRadar v0.1

Визуальный язык: **классический Macintosh (Mac OS 8/9 «Platinum») + инженерная терминальная
консоль**. Метафора продукта: рабочий стол диагностической станции — платиновые окна с
рельефными рамками, внутри которых живут тёмные терминальные панели сканера.

Референс тона: System 8 Finder + серийная консоль. Современное качество: адаптивность,
контраст, клавиатурная навигация, состояния loading/error/success/empty.

---

## 1. Палитра

CSS custom properties (тема одна, светлая «Platinum»; терминальные панели — локально тёмные).

### Platinum (хром окон)

| Токен | Значение | Использование |
|---|---|---|
| `--plat-50`  | `#efefef` | светлые грани, фон полей ввода |
| `--plat-100` | `#dddddd` | **основной фон окон и панелей** |
| `--plat-200` | `#cccccc` | фон рабочего стола (с паттерном), неактивные заголовки |
| `--plat-300` | `#aaaaaa` | тёмные грани bevel, разделители |
| `--plat-400` | `#888888` | глубокие тени bevel, disabled-текст |
| `--plat-600` | `#555555` | вторичный текст |
| `--plat-900` | `#111111` | основной текст, рамки окон |
| `--desktop`  | `#66799b` | фон рабочего стола (сине-серый, как default Mac OS 8) |

### Терминал

| Токен | Значение | Использование |
|---|---|---|
| `--term-bg`     | `#101410` | фон терминальных панелей |
| `--term-green`  | `#33ff66` | основной терминальный текст, прогресс |
| `--term-amber`  | `#ffb000` | предупреждения, warning-статусы |
| `--term-cyan`   | `#4dd0e1` | ссылки/акценты в терминале, URL |
| `--term-dim`    | `#1d824a` | вторичный терминальный текст, timestamps |
| `--term-red`    | `#ff5544` | ошибки, fail-статусы |

### Семантика статусов (единая для UI и терминала)

| Статус | Chip на Platinum | В терминале |
|---|---|---|
| ok / pass / Completed | текст `#1a6b2f` на `#d6efd9`, рамка `#1a6b2f` | `--term-green` |
| warning / Partial / Provisional | текст `#8a5b00` на `#ffe9c2`, рамка `#8a5b00` | `--term-amber` |
| error / Failed / Critical | текст `#9b1c12` на `#ffd9d4`, рамка `#9b1c12` | `--term-red` |
| info / Running / Queued | текст `#1a4f8a` на `#d7e6f7`, рамка `#1a4f8a` | `--term-cyan` |
| neutral / Unavailable / Not applicable | текст `--plat-600` на `--plat-100`, рамка `--plat-400` | `--term-dim` |

Severity: Critical=error, High=`#c2410c` (оранжево-красный chip), Medium=warning, Low=neutral.

Выделение (selection): `#333399` фон + белый текст (классический Mac highlight).
Focus-ring: `2px dotted #333399` со смещением 1px (пиксельный dotted — ретро и видимый).

## 2. Типографика

| Роль | Шрифт | Размер/интерлиньяж |
|---|---|---|
| UI (заголовки окон, меню, кнопки, лейблы) | `"Charcoal", "Chicago", "Geneva", "Helvetica Neue", system-ui, sans-serif` | 13px/1.3; заголовки окон 13px bold |
| Основной текст, таблицы | тот же UI-стек | 13px/1.45 |
| Терминал, код, URL, ID, метрики, логи | `"Monaco", "SF Mono", "Menlo", "Courier New", monospace` | 12px/1.6 |
| Крупные цифры score | monospace | 34px/1.1, bold |

Правила: НИКАКИХ тонких весов (<400). Все технические данные (URL, fingerprint, scan_id,
score, HTTP-статусы, timestamps) — только monospace. `font-smooth: never` не применяем —
читаемость важнее аутентичности; пиксельность достигается рамками, не шрифтом.

## 3. Сетка, размеры, отступы

- Базовый шаг: **4px**. Токены: `--sp-1..--sp-8` = 4/8/12/16/20/24/32/48.
- Скругления: `--r-0: 0` (панели, поля, таблицы), `--r-1: 2px` (кнопки),
  окна — 0px с фаской-«ушками» опционально. Больших скруглений нет.
- Высоты контролов: кнопка 24px, поле ввода 24px, строка таблицы 28px, заголовок окна 22px.
- Контентная ширина: max 1100px; двухколоночный дашборд от 900px.

## 4. Bevel — базовый строительный приём

Все рельефы — только `box-shadow`/`border` из палитры, без градиентов и blur:

- **Raised (панель/кнопка):**
  `border: 1px solid var(--plat-900);`
  `box-shadow: inset 1px 1px 0 #ffffff, inset -1px -1px 0 var(--plat-300);`
- **Sunken (поле, терминал-колодец, таблица):**
  `border: 1px solid var(--plat-400);`
  `box-shadow: inset 1px 1px 0 var(--plat-300), inset -1px -1px 0 #ffffff;`
- **Pressed (кнопка:active):** фон `--plat-300`, тени raised инвертированы, контент сдвиг +1px/+1px.

## 5. Окно (Window) — главный контейнер

- Рамка: `1px solid var(--plat-900)`, фон `--plat-100`, внешняя тень `2px 2px 0 rgba(0,0,0,.35)`.
- **Title bar** (22px): классические горизонтальные полоски (repeating-linear-gradient
  `#fff 0 1px, var(--plat-200) 1px 2px`) по бокам от центрированного названия;
  название 13px bold на плашке фона `--plat-100`.
  Слева квадратная close-box (12×12, raised), справа — zoom-box. В неактивном окне полоски
  скрыты, текст `--plat-400`.
- Контент: padding `--sp-4`.
- Разновидности: `window--dialog` (уже, с кнопочной панелью снизу справа),
  `window--terminal` (контент без padding, внутри терминальная панель).
- На мобильных окна становятся full-width карточками, сохраняют title bar.

## 6. Панели и терминал

- **Panel** — raised-блок внутри окна для группировки; заголовок-«этикетка» 11px UPPERCASE
  `--plat-600` с letter-spacing 0.08em.
- **Terminal well** — sunken-рамка, внутри `--term-bg`, padding `--sp-3`, monospace 12px.
  Строки: `[10:42:07] GET /pricing → 200 (312 ms)`; timestamp `--term-dim`, URL `--term-cyan`,
  статус по семантике. Prompt-строка начинается с `fluxradar>` в `--term-green`.
  Курсор: блочный `▮`, мигание `steps(2)` 1.1s (отключается при `prefers-reduced-motion`).
- Прогресс скана: ASCII-бар `[██████░░░░] 60% · 312/520 URL` + построчный лог модулей.

## 7. Контролы

- **Button (default):** raised, фон `--plat-100`, 24px, padding 0 12px, текст 13px.
  Primary-вариант: двойная рамка (внешняя 1px `--plat-900` + отступ 2px + внутренняя 1px) —
  классическая «default button» Mac OS; активируется Enter-ом.
  Danger: текст `#9b1c12`. Disabled: текст `--plat-400`, тени сохраняются, курсор default.
- **Input / Select / Textarea:** sunken, фон `#ffffff`, monospace для технических значений
  (домен, URL), UI-шрифт для остального. Placeholder `--plat-400`. Error-состояние: рамка
  `#9b1c12` + подпись 11px под полем.
- **Checkbox/Radio:** 12×12 sunken квадрат/круг, отметка — пиксельный ✕/■ цвета `--plat-900`.
- **Tabs:** «папочные» вкладки — raised трапеции без скруглений сверху, активная сливается
  с панелью (нет нижней грани), неактивная — фон `--plat-200`.
- **Progress bar:** sunken желоб 12px, заполнение — «зебра» из диагональных полос
  `#333399`/`#5555bb` (в терминале — ASCII-бар).
- **Menu bar** (верх приложения): 22px полоса `--plat-100` с нижней гранью; пункты —
  Файл/Скан/Отчёты/Справка-стиль; выпадающие меню — raised-панели, hover-инверсия selection-цветом.

## 8. Таблицы, списки, навигация

- **Таблица (Issue Center):** сплошная sunken-рамка; header 24px raised, 11px UPPERCASE;
  строки 28px, зебра `#ffffff`/`--plat-50`; выбранная строка — selection-инверсия;
  сортировка — стрелка ▲▼. Технические колонки (URL, rule_id, severity) — monospace.
  На узких экранах таблица превращается в стопку карточек-строк (label: value).
- **Списки-деревья** (модули скана): строки 24px с пиксельными ▸/▾ и иконками 16×16.
- **Иконки:** пиксельные 16×16 (инлайновый SVG с `shape-rendering: crispEdges`),
  один цвет `--plat-900` + семантический акцент.
- **Навигация приложения:** menu bar сверху + «рабочий стол» с окнами-разделами; на mobile —
  окна в столбик, menu bar скроллится горизонтально.
- **Breadcrumb / статусная строка** внизу окна: 18px sunken полоска, monospace 11px —
  `scan_01J… · rules-mvp-0.1 · coverage 0.87`.

## 9. Состояния компонентов

Обязательны для каждого экрана данных:

- **Loading:** терминальная строка `loading… ▮` или ASCII-спиннер `|/-\` (steps-анимация);
  для таблиц — 3 строки-скелета из символов `░░░░░`.
- **Empty:** пиксельная иконка папки + однострочное объяснение + primary-действие
  («Проблем не найдено — запустите новый скан»).
- **Error:** классический Mac alert-диалог: иконка ⚠ слева, текст, кнопки справа снизу
  (primary = безопасное действие). Технические детали — в сворачиваемом терминал-колодце.
- **Success:** статусный chip + строка в терминал-логе; без тостов-оверлеев.
- **Score-состояния:** число + метка методики `score-v1`; `Provisional` — amber-chip рядом;
  `Insufficient data` — вместо числа, neutral-chip, объяснение coverage.
- Анимации: только курсор, спиннер, зебра прогресса (движение фона 0.5s steps(8)) и
  «раскрытие» окна (scale 0.98→1, 120ms). Всё отключается `prefers-reduced-motion`.

## 10. Адаптивность

- Брейкпоинты: `≥1100` рабочий стол (окна в 2 колонки), `700–1099` одна колонка окон,
  `<700` mobile: окна = full-width карточки, таблицы = карточки-строки, menu bar скроллится,
  минимальная tap-цель 40×40 (контрол остаётся визуально 24px внутри отступов).
- Терминальные панели: горизонтальный скролл вместо переноса длинных URL (сохранение
  читаемости лога), `overflow-wrap` только для прозы.
- Контраст: весь текст ≥ 4.5:1 (проверено для пар выше); терминал `--term-green` на
  `--term-bg` ≈ 10:1; `--term-dim` — только вторичные метки ≥ 3:1 + не единственный носитель смысла.
- Клавиатура: полный tab-порядок, focus-ring обязателен, Enter = default button,
  Esc закрывает диалог; таблицы — стрелки вверх/вниз по строкам.

## 11. Запрещено

Современный SaaS-стиль, glassmorphism, большие скругления (>4px), градиенты (кроме
полосок title bar и зебры прогресса), тени с blur > 0, неоновые свечения, эмодзи в UI-хроме,
крупные пустые hero-блоки, тосты-оверлеи, спиннеры-круги.

## 12. Реализация

- `apps/web/src/styles/tokens.css` — все токены; `apps/web/src/styles/base.css` — reset+bevel-утилиты.
- Компоненты: `Window`, `MenuBar`, `Panel`, `Terminal`, `Button`, `Input`, `Select`, `Checkbox`,
  `Tabs`, `DataTable`, `StatusChip`, `ScoreDial` (число+chip), `ProgressBar`, `AlertDialog`,
  `EmptyState`, `FieldRow`. Каждый — с состояниями из §9.
- Никаких UI-библиотек; иконки — собственные пиксельные SVG.
